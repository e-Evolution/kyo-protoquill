# Code of Conduct (Draft)

## Status

This is a **review draft** governance baseline, not the repository's live
root-level `CODE_OF_CONDUCT.md`. Neither the fork nor its parent
`zio/zio-protoquill` has a `CODE_OF_CONDUCT.md` at any level, so there is no
upstream template to adapt. It is destination-independent: it names no
contact address, handle, or repository-specific reporting channel.

## Code-of-Conduct Expectations

- Participants are expected to communicate respectfully in issues, pull
  requests, and any other project space, and to refrain from harassment,
  discriminatory language, or personal attacks.
- Maintainers are expected to moderate reported violations and may remove
  content or restrict participation that violates these expectations.
- This draft does not name who fills the moderator/maintainer role; that
  question is the same `governance_approver`/`repository_owner` gap
  recorded as unassigned in
  `docs/publication-readiness/destination-decision.yaml`.
- Private reporting of a conduct concern follows the same private-channel
  expectation recorded in
  `docs/publication-readiness/governance/security.md`; no separate
  public contact is invented here.
- No response-time commitment is made; none is confirmed by any named
  owner as of this draft.
